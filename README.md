# アルカナ・フィールド (ARCANA FIELD)

**動く大地の上で戦う 3D フィールドカードゲーム。思考する AI と対戦できます。**

ブラウザだけで動作します (ビルド不要・画像/音声ファイル不要)。3D モデル、カードイラスト、地形テクスチャ、効果音、BGM はすべてコードで手続き的に生成しています。

## 遊び方

```bash
npm start          # http://localhost:8080 で起動 (npx http-server)
# または任意の静的サーバーで index.html を配信
python3 -m http.server 8080
```

> ES Modules と importmap を使っているため、`file://` で直接開くのではなく HTTP サーバー経由で開いてください。

## ゲームの概要

| 要素 | 内容 |
| --- | --- |
| 盤面 | 7×7 の立体マス。地形 (平原/森/水辺/溶岩/マナ結晶/聖域) と高さ (0〜3) を持つ |
| 勝利条件 | 相手の **将** (HP16) を倒す |
| マナ | 毎ターン最大マナ+1 (上限10)。マナ結晶に自軍がいると+1 |
| ユニット | 1ターンに移動1回・攻撃1回。反撃あり。召喚酔いあり (突撃を除く) |
| 指揮力 | 毎ターン3。移動・攻撃で1、移動して攻撃で2消費。全ユニット合計で動かせる回数に上限がある。将の移動は消費なし |
| 将の移動 | 1ターンに1マス。地形の移動コストや1段の段差の影響を受けない (崖は不可) |
| 高低差 | 高所からの攻撃はダメージ+1、高さ2以上の遠隔ユニットは射程+1、崖 (段差2以上) は登れない |
| 侵攻 | 敵陣 (相手側の奥2列) にいる自軍ユニット1体につき、ターン開始時に敵の将へ1ダメージ |
| **動く大地** | 地形カードで隆起・沈降・行のスライド・3×3 区画の回転が可能。上のユニットも一緒に動く |
| 奥義 | 一部の伝説ユニットが1回だけ使える、盤面全体を変える技 (攻撃の代わり・指揮力1) |
| 環境 | 一部の伝説ユニットが場にいる間、空模様と全体のルールが変わる (焦天・恵みの霧雨・無重力の星海・研究室) |
| 地殻変動 | 3ラウンドごとに中央8マスが回転、または大地が隆起・沈降する |

### 勢力とデッキ構築

- **紅蓮帝国** 🔥 — 突撃ユニットと火力呪文、溶岩を生む速攻型。英雄の力「火花」
- **翠緑の森** 🌿 — 森を広げ大地を隆起させる守りと回復。英雄の力「芽吹き」
- **蒼穹機関** ⚙️ — 行をずらし陣を回転させ戦場そのものを組み替える。英雄の力「衝撃波」
- **雷研究室** ⚡ — 「没入の実験体」を次々と送り出して数で押す。英雄の力「被験体投入」
- **双翼の竜** 🐉 — エンハンスと最大マナの増加で巨竜を呼ぶランプ型。英雄の力「竜の喧伝」

カードは全 121 種類 (各勢力 20 種 + 中立 21 種)。キーワード: 突撃・飛行・守護 (ZOC)・耐火・貫通・爆炎・森の民・遠隔・鉄壁・再生・凍結・遺言・不動。

**デッキ編成**: タイトル画面の「🃏 デッキ編成」で、勢力のカードと中立カードから 30 枚のデッキを組めます
(同じカードは 2 枚まで、★ の強力なカードは 1 枚まで)。各勢力に構築済みデッキが 2 種類あり、
マイデッキは勢力ごとに 3 つまでブラウザに保存されます。「おまかせで埋める」「構築済みを読み込む」も使えます。
AI は相手勢力の構築済みデッキからランダムに 1 つを使います。

**ティア表**: 「🏆 ティア表」で、構築済みデッキ同士を AI で総当たりさせた結果 (勢力・デッキのティアと相性表) を見られます。
`npm run tier [-- 各組み合わせの対戦数]` で `src/data/tier.js` を作り直します。

## AI のしくみ (`src/engine/ai.js`)

1. **評価関数** — リーダーHP (残りが少ないほど重く)、ユニットの戦力値、前進度、地形 (結晶・溶岩・高所・森)、
   そして「相手が次のターンに各マスへ与えうるダメージ」を移動範囲+射程から計算した **脅威マップ** を合成して局面を数値化。
2. **ビームサーチ** — 候補手 (召喚位置・呪文の対象・移動・移動+攻撃・英雄の力) を列挙し、複製した盤面に適用して評価。
   上位 B 局面だけを残しながら 1 ターン分の行動列を最大 14〜16 手先まで探索する。
3. **応手読み** — 最終候補について「相手が盤上の駒で最善に応じたら」を貪欲法でシミュレートし、スコアを補正 (熟練・達人)。
4. **公平性** — AI はあなたの手札や山札の中身を見ません。シミュレーション中に引くカードは「不明なカード」として扱い、実際に引いた後で計画を立て直します。

| 難易度 | ビーム幅 | 応手読み | 特徴 |
| --- | --- | --- | --- |
| 見習い | 2 | なし | 評価にノイズが乗り、ときどき甘い手を指す |
| 熟練 | 4 | 上位2案 | 数手先まで読む標準的な強さ |
| 達人 | 4 | 上位4案 (重視) | 相手の反撃を強く警戒する |

AI 同士の自己対戦で調整しており、勢力間の勝率はほぼ均等、難易度は 達人 > 熟練 > 見習い の順に勝ち越します。

画面右上の **AI 思考パネル** で、評価した局面数・探索深さ・思考時間・計画中の手順・意図 (攻勢/防衛/展開…) がリアルタイムに見られます。
盤上には AI が検討中のマスがうっすら表示されます。**💡助言** ボタンを押すと、同じ AI があなたの最善手を提案します。

## 操作

| 操作 | 内容 |
| --- | --- |
| 左クリック | ユニット選択 / 移動 / 攻撃 / カード使用 |
| 右クリック・Esc | キャンセル |
| 右ドラッグ / ホイール / 中ドラッグ | 視点の回転 / ズーム / 平行移動 |
| Q / E | 視点を 90 度回転 |
| T / R | 真上から / 視点リセット |
| Enter | ターン終了 |
| H / V | AI の助言 / 敵の脅威範囲表示 |
| 1〜9 | 手札のカードを選択 |

スマートフォンの縦画面にも対応しています (1本指で回転、2本指でズーム)。

## 構成

```
index.html, style.css      UI のレイアウトとスタイル
src/main.js                 起動・タイトル画面・設定
src/game.js                 対局の進行 (入力、演出、AI の駆動)
src/engine/                 描画に依存しない純粋なゲームロジック
  rules.js                  ルール・行動・イベント生成
  cards.js                  カード/勢力/キーワード定義
  maps.js                   戦場 (固定3種 + ランダム生成)
  ai.js                     評価関数・ビームサーチ・応手読み
  rng.js                    決定論的乱数
src/render/                 Three.js による 3D 描画
  view.js                   盤面・カメラ・イベント演出
  models.js                 25種以上のユニット模型 (プリミティブの組み合わせ)
  fx.js                     パーティクル・飛び道具・稲妻・衝撃波
  textures.js               地形などの手続き的テクスチャ
  cardart.js                3D 模型を撮影してカードイラストを生成
src/ui/                     HTML の HUD・カード表示
src/audio.js                WebAudio による効果音と BGM の合成
vendor/three/               Three.js r170 (MIT)
tests/                      ルールエンジンと AI のテスト
```

## アップデート履歴

ゲーム内のタイトル画面・メニューの「📜 更新履歴」、または [CHANGELOG.md](CHANGELOG.md) を参照。


ルール (移動・崖・守護・戦闘・地形・行スライド・回転・地殻変動・侵攻・溶岩・決着) と AI (詰みの発見、評価関数の対称性、AI 同士の対局が必ず決着すること) を検証します。
